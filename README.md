# Intello

Intello was a SaaS management platform providing SaaS discovery, usage analytics, and spend optimization for IT teams seeking visibility and control over their software portfolio. The product line is now offered by Zylo, an enterprise SaaS spend optimization and AI consumption cost management platform. There is no separate public developer API.
